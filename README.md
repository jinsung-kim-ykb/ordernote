# 오더노트 (OrderNote) — 식자재 유통사 카톡 주문 입력 도구

식당이 카카오톡으로 보낸 주문("대파 2단, 어제 거 그대로")을 유통사 담당자가 **붙여넣기만 하면**
품목 사전으로 해석해서 **배송표 엑셀 · 피킹리스트 · 거래처 확인서 · 이카운트 업로드 파일**을 만들고,
확신이 없는 줄만 **확인 큐**로 묻습니다. 식당은 하던 대로 카톡으로 주문하고 아무것도 설치하지 않습니다.

- **식당은 그대로** — 카톡 "대화 내보내기" 텍스트(안드로이드·아이폰·PC·맥)나 메시지 복사본을 그대로 붙여넣습니다.
- **사용할수록 정확해진다** — 확인 큐에서 고른 표현이 품목 사전의 별칭·단위 환산으로 쌓입니다. 거래처별 별칭도 됩니다.
- **틀리게 넣느니 묻는다** — 사전에 없는 표현, 애매한 후보, 수량 불명확, 수정·취소 표현은 자동 확정하지 않습니다.

서버·가입 없이 브라우저에서 돕니다. 데이터는 **그 주소·그 브라우저에만** 저장되고 JSON 백업으로 옮깁니다.

## 바로 써 보기

| 방법 | 주소 | 특징 |
|---|---|---|
| claude.ai 링크 | 소유자가 공유한 링크 | 설치 없음. AI 해석을 **보는 사람의 claude.ai 계정**으로 호출(키 불필요). 데모·검토용 |
| GitHub Pages | `https://<사용자명>.github.io/playground_youtube/` | 고정 주소. 유통사에 주는 공식 주소. AI는 Anthropic API 키(선택) |
| 로컬 | 저장소 폴더에서 `python3 -m http.server` → http://localhost:8000 | 오프라인 |

**Pages 켜기**: 저장소를 Public으로 → Settings → Pages → Source *Deploy from a branch* → Branch `claude/admiring-allen-bobzah`, `/ (root)` → Save.
`index.html`을 더블클릭으로 열면 샘플 데이터 파일을 못 읽습니다(서버로 여세요).

## 담당자의 하루 (7pm–1am)

1. **시작**: 처음 열면 "우리 주문 시작(기본 식자재 사전 200개 내장)" / "내 품목 CSV로 시작(이카운트 품목 내보내기 그대로 가능)" / "샘플로 둘러보기" 중 하나.
2. **붙여넣기**: 카톡 방을 하나씩 내보내거나 복사해서 붙여넣습니다. 붙여넣는 즉시 처리됩니다(기본 방식). 같은 방을 다시 붙여넣어도 중복 메시지는 빠지고, 여러 방에 다 나오는 발신자는 "우리 담당자"로 자동 제외됩니다.
3. **확인 큐**: "처음부터 차례로 해결"을 누르면 한 줄씩 후보 품목(숫자키)·수량을 고릅니다. 같은 표현은 함께 해결되고, 사전에 없으면 그 자리에서 "새 품목으로 등록". 고른 표현은 별칭으로 기억됩니다.
4. **출력**: 배송표 엑셀(피킹리스트 + 거래처별 시트, 확인필요 노란색), 피킹리스트·배송표 인쇄, 이카운트 "판매입력 → 웹자료올리기" 서식 엑셀 또는 붙여넣기용 복사, 확인큐 CSV.
5. **확인서**: 거래처별 확인 문구를 복사해 카톡에 붙여넣습니다. 복사하면 "보냄"으로 표시되고 다음 거래처로 넘어갑니다. (알림톡 자동 발송은 비즈니스 채널 심사 후)
6. **납품분 확정**: 거래처별 직전 주문이 갱신되어 다음날 "어제 거 그대로"가 풀리고, 기록에 지표가 쌓이고, 백업 JSON이 내려받아집니다. 확정 뒤 들어온 주문은 "추가분"으로 표시됩니다.

## 기록 화면의 지표 (사업계획 목표)
- **자동 처리율** = 확인 큐 없이 바로 확정된 줄 / 전체 줄 — 목표 85%
- **확인 큐 비율** = 확정 시점에 남은 줄 / 전체 줄 — 목표 15% 이하
- **하루 처리 시간** = 첫 붙여넣기 ~ 확정, 설정의 "도입 전 소요 시간" 대비 단축률 — 목표 50%
- **학습된 별칭 수** — 사용할수록 자동 처리율이 오르는 근거
샘플 모드의 기록은 실제 통계에 섞이지 않습니다.

## 구조

```
index.html          화면
web/core.js         파서·규칙 엔진·매칭·단위 환산·확인서 (ordernote/*.py 와 같은 로직, 같은 정답셋으로 검증)
web/kakao.js        카톡 내보내기/복사본 파서 (안드로이드·아이폰·PC·맥 CSV), 발신자·방 구분, 메시지 병합·중복 제거
web/store.js        작업공간 저장(localStorage): 품목 사전·거래처·거래처별 별칭·기록·오늘 작업, 백업 JSON
web/app.js          화면 로직. window.claude 유무로 GitHub Pages / claude.ai Artifact 환경을 구분
web/build_artifact.py  claude.ai Artifact 용 단일 HTML 생성 (capabilities: sample, downloads)
web/vendor/         Anthropic SDK 번들, ExcelJS (CDN 없이 동작)
ordernote/          Python CLI (원래 데모) — run-windows.bat / run-mac.sh 로 실행
data/, input/       기본 식자재 사전 200개(items_default.csv), 샘플 사전 50개·거래처 5곳·주문 20건·정답셋
```

### 해석 방식
| | 기본 (규칙) | AI |
|---|---|---|
| 동작 | 품목 사전·별칭에 있는 표현, 수량 단위(단·망·근·박스·kg·판·통·봉·개·반), "어제/평소/지난번 그대로"+수량 변경·제외 | LLM이 메시지를 품목 줄로 구조화(JSON 스키마 검증, 실패 시 재시도 1회) |
| 비용 | 없음, 즉시 | Pages: Anthropic API 키 / claude.ai 링크: 보는 사람 계정 |
| 실패 시 | — | 그 주문은 자동으로 기본 방식으로 처리(밤에 멈추지 않음) |

### 검증
```bash
node web/eval.test.cjs      # 샘플 20건 정답셋: 잘못 매칭 0건
node web/store.test.cjs     # 작업공간·카톡 형식·학습·확정 흐름
python -m ordernote --eval data/expected.json   # CLI 동일 검증
```

## CLI (원래 데모)
`run-windows.bat`(더블클릭) / `bash run-mac.sh` 가 Python 3.11+ 확인 → 가상환경 → 패키지 설치 → 샘플 처리 → `output/` 폴더를 엽니다.
`LLM_API_KEY`를 넣으면 AI 엔진, 없으면 규칙 엔진. 자세한 옵션: `python -m ordernote --help`.
